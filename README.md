One short joke about office life, written as a single line — the sort
you send a colleague after a meeting that should have been an email.
The printer is the only coworker that never misses a deadline: it
just eats the paper instead.

## The joke

> Our office printer only jams on documents due in five minutes — it's the one coworker that actually reads the deadline.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, no dependencies) writes the joke to
`/output/entry.txt`. It uses no network and no randomness, so every
run produces identical bytes.
